# Vesper

面向 Windows 的家庭 KTV 软件，采用 C#、.NET、WinUI 3、MVVM 与 Fluent。首版以本地曲库为基础，完成找歌、排队与演唱；后续手机点歌采用局域网网页。

当前为工程原型：曲库、收藏、歌曲详情、联网资料/歌词、搜索、待播队列、本地艺人/专辑页及详情本地媒体预览／居中胶囊已接入，仍有真实曲库和界面待验收。首页艺人／推荐／收藏与本地视频演唱已接入，实际界面／听感待验收；创作编辑及无视频歌词演唱尚未完成，具体状态见接续摘要。

## 开始开发

```powershell
git clone https://github.com/Casper-003/Vesper.git
```

使用 Visual Studio 打开 `Vesper.slnx`，将 `Vesper.App` 设为启动项目，选择 x64 与 Unpackaged 配置。命令行构建及数据/控件检查见开发与调试。

每人/每台电脑使用独立克隆。分支、身份与同步约定见 AGENTS；个人曲库、录音、缓存、凭据和本机配置不入库。
