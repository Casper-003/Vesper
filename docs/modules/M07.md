# M07 歌词体验

更新：2026-11-16。已集成 `Lyricify.Lyrics.Helper 0.2.1`（Apache-2.0，不涉及闭源主程序及美术资源）实现多源逐字／逐行自动补全与解析，并按用户最新要求改为直接通过 `WebView2` 托管 `folia-major`（`chthollyphile/folia-major`，AGPL-3.0，离线构建产物置于 `Assets/FoliaStage`）真实前端视觉引擎渲染全屏歌词舞台；小窗继续保持取色流光背景不展示歌词。尚待真实曲库手动验收匹配率、Folia 各模式观感及全屏「匹配／修改歌词」弹窗交互，MV 自带歌词叠加策略仍待后续确定。

## 已确认

- 2026-11-16 用户确认（无 MV 场景）：
  - **获取途径**：接入 `WXRIW/Lyricify-Lyrics-Helper` 能力，优先后台／进场前**自动化匹配补全**并缓存，若歌词不匹配可由用户**手动搜索切换、编辑或微调时间偏移**（手动指定后设 `LyricsManualOverride = true`，防止后台自动查找覆盖）。
  - **显示途径**：**小窗只展示动态流光背景**（首页中心大屏幕与非首页右上角预览小卡片，均不展示歌词、也不直接贴静态专辑封面图），**进入全屏演唱模式才展示动态歌词**；经初版原生复刻观感评估后，用户确认**改按 `folia-major` 原版引擎渲染全屏歌词**（允许切换重着色器模式时短暂读条）。
- 细节规则：保留版本选择、偏移调整和逐行回退，不保证任意曲都有逐字数据；详情默认自动检索，不让搜索／选结果成为普通操作必经步骤。无 MV 时背景与逐字／逐行歌词跟随真实播放时间轴，绝不把逐行文本伪作逐字时间轴。

## 已接入与边界

- **多源检索与解析（`src/Vesper.Core/LyricifyService.cs`、`LyricsModels.cs`、`CoverPalette.cs`）**：
  - 本地旁路优先检查同目录同文件名 `.qrc` / `.yrc` / `.krc` / `.ttml` / `.lrc` 文件（`LyricsManualOverride == false` 时），随后读取缓存的 `OnlineLyrics`（优先 `WordLyricsFile` 逐字数据）或内嵌 `Local.Lyrics`。
  - 启动后台继续保留防限流检索（`AdditionalSongSources` 已补充提取网易云 `&yv=-1` 逐字 `yrc` 与 `tlyric` 翻译）；进入无 MV 演唱或打开歌词弹窗时通过 `LyricifyService.SearchCandidatesAsync` 并行查询 QQ 音乐（解密 QRC＋翻译）、网易云（YRC/LRC＋翻译）、酷狗音乐（解密 KRC）与 LRCLIB，结合 `LrcLibClient.Choose` 与 `SongNameMatching` 自动择优补全并缓存。
  - 使用 `Lyricify.Lyrics.Helpers.ParseHelper.ParseLyrics` 与回退解析器统一输出 `ParsedLyrics`，明确区分 `HasWordSync`（仅当存在真实音节时间戳时置 `true`）、`HasLineSync`（逐行 LRC）与纯文本，清除 `[id:]`、`[hash:]` 等元数据标签。
- **Folia 原版视觉舞台与小窗流光（`FoliaFluidBackground.cs`、`FoliaLyricsStage.cs`、`Assets/FoliaStage/`）**：
  - `FoliaFluidBackground` 从歌曲封面主色生成四色阶调色板（`CoverPalette.CreateFluidPalette`），以渐变柔光球服务首页中心大屏幕、右上角小预览窗（不显示歌词）及全屏 `WebView2` 初始化前的底层零闪烁过渡。
  - `FoliaLyricsStage` 通过 `WebView2` 虚拟主机（`https://folia.vesper.local/`，`WEBVIEW2_USER_DATA_FOLDER` 指向 `%LocalAppData%\Vesper\WebView2`）托管 `folia-major` `VisualizerRenderer`，接收 C# 推送的原始歌词（TTML/YRC/QRC/KRC/LRC）、已解析逐字退化数据、封面 URL、提取调色板、`duration`/`position`/`paused`/`offsetMs` 与工具栏显隐状态；前端使用 Folia 自身的 `parseLyricsByFormat`／`finalizeParsedLyricLines` 生成 `renderHints` 与间奏段落，支持切换 Folia 全量 **17 种歌词视觉模式**（流光 `classic`、绘光 `lumiere`、雾笺 `nebbia`（含 `nebbia-strokes.json` 笔顺）、镜台 `diorama` 3D、时计 `pendolo`、商籁 `sonnet`、凝彩 `tempera`、莫奈 `monet`、云阶 `partita`、心象 `cadenza`、浮名 `fume`、回环 `claddagh`、群唱 `cappella`、花火 `hanabi`、町景 `machi`、倾诉 `tilt`、静止 `still`）与 **5 种背景氛围**（隐现 `latent`、通用 `common`、莫奈 `monet`、漫游 `nomand`、空 `sora`），切换重模式或在线搜词时显示轻量加载提示条，并支持点击歌词行跳转与唤醒底部播控栏。
  - 许可保留于 `src/Vesper.App/ThirdParty/folia-major.LICENSE.txt`（AGPL-3.0）及 `src/Vesper.App/Assets/FoliaStage/licenses/nebbia-strokes/`（Arphic Public License / AnimCJK `COPYING.txt`），均复制至输出目录。
- **手动修正入口与闪退修复（`SongDetailsView.xaml`、`SingingView.cs`、`MainWindow.Details.cs`）**：
  - 详情页「歌词」标题右侧与全屏歌词控制栏共设「匹配／修改歌词」弹窗（全屏栏以图标按钮呈现，点击可打开检索/偏移/手动编辑窗口）。
  - 修复全屏点击列表/歌词管理按钮时因重复将同一 `ProgressRing` 添加至父面板引起的 `0x800F1000` 闪退，并将 `LyricsCandidateOption` 调整为 `public`。
- 当前自动音频包络驱动 Folia 响应式着色器（未接独立解码 FFT 频谱），多源覆盖率、WebView2 首次初始化耗时及各 Folia 样式实际观感仍须真实曲库人工验收。
