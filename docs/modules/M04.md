# M04 演唱画面与本场流程

更新：2026-11-06。本地视频演唱界面与本场流程已接入，实际画面／听感及全屏往返待用户验收；无视频的歌词演唱仍待后续实施。胶囊展开后的演唱卡片作为进入演唱界面的入口，具体规则见下文；不恢复 [M01](M01.md) 已撤回的顶部播放控件。队列整理归 [M03](M03.md)。

## 播放底层实施状态

2026-11-04：P0.1 已新增 `LocalMediaPlayback`，以 Windows MediaPlayer／MediaPlayerElement 播放本地文件：异步准备（不自动播放）、播放／暂停、视频表面解绑／重绑、自然结束与运行错误通知、取消／20 秒准备超时、替换请求和资源释放。每次准备使用独立播放器，旧请求及旧原生事件不能覆盖新资源。该阶段正常启动尚未接线，不增加产品入口；后续接线见下段。

2026-11-06：已新增 `SingingSession`／`SingingView`／`MainWindow.Singing.cs`，接入本地视频表面、全屏与返回浏览、暂停／定位、自动续播、切歌、等待及退出。进入前使用系统 MediaComposition 解码零时刻实际视频帧，作为展开时的 XAML 图像；准备与呈现完成后开始播放，媒体时钟推进后移去首帧覆盖。`MediaOpened` 不等于画面呈现；渲染节拍也不等于普通原生视频表面已呈现的像素证据，真实切换／听感仍须人工验收。读取首帧或播放失败时释放资源，当前歌回待播队首并明确提示。复现与证据见 [开发与调试](../开发与调试.md)／[验证记录](../验证记录.md)。

## 演唱画面与切换

- 2026-11-06 用户确认：点击胶囊展开后的演唱卡片进入演唱界面。卡片只作入口，不放进度条、播放／暂停、返回或停止控件；操作集中在演唱界面，保持入口简洁。无当前歌曲且有待播时，点击卡片直接从队首开始；有当前歌曲时返回当前演唱。现阶段控件范围与排布见下文，不将“完整操作”扩大为其他音频或麦克风控件均已定稿。
- 常态视频全屏，取消同屏选歌分屏及双显示器方案，不保留 2:1 布局或指定／记住演唱屏幕。进入前准备播放资源与首帧，展开至全屏；常规切歌轻量反馈，具体节奏待原型验证。
- 2026-11-04 用户确认：正式播放使用 Vesper 窗口内嵌播放器，不弹独立播放窗口、不调用外部播放器；隔离自动检查窗口仅为开发验证工具。全屏演唱与返回选歌沿用应用内切换。
- 返回 M01 主界面选歌时，原播放继续、声音不中断，原暂停保持暂停；点击胶囊展开后的演唱卡片再回全屏，保留当前进度及播放／暂停，不重新开始或自行恢复。
- 音乐文件识别后自动匹配 MV，可靠时采用，不要求普通用户逐个比较候选；无匹配时用流光背景与逐字歌词。此为正在唱歌的画面，区别于队列播完的等待画面。识别来源归 M02，音频版本和时间轴归 M07。
- 流光样式、歌词排版、无逐字数据处理，以及是否导出视频尚未定稿。

## 控制栏与暂停

- 2026-11-06 用户确认：演唱进度条同时实现“可拖动定位”和“仅显示进度”两种模式，由用户在设置页选择，默认“可拖动定位”，便于跳过前奏或重唱片段；仅显示模式不接受进度定位操作，供需要避免误触的用户选择。不将该选择放到胶囊演唱卡片上。
- 2026-11-06 用户确认：演唱界面的控件按钮采用磨砂玻璃材质，以图标表达操作、悬停显示说明；不额外套圈或绘制圆环边框，图标下方的圆形背景本身呈现半透明、模糊透色的磨砂玻璃质感。具体尺寸与材质观感待后续设计及实际画面验收。
- 移动鼠标或轻触全屏画面呼出底部控制栏；播放中连续 3 秒无操作整栏隐藏，暂停期间持续显示。3 秒为当前设计值，需体验验证。
- 2026-11-06 用户确认底栏排布：进度条位于按钮上方；左侧“返回选歌”，中间“暂停／继续”和“切歌”，两者留出间距；最右“退出本场”，与常用操作隔开。进度条与按钮均随整栏显示／隐藏。
- 2026-11-06 用户确认：演唱控制栏加入磨砂玻璃材质的“切歌”按钮，点击直接切至待播下一首，无需返回选歌页；与暂停按钮保持一定间距以减少误触。待播为空时，点击切歌结束当前歌曲并进入等待画面，与队列唱完后的状态一致。
- 暂停时 MV 停当前帧、声音暂停，明显的“继续演唱”按钮持续显示，不因无操作消失；不切分屏。选歌／演唱往返仍暂停。
- 点击“继续演唱”才从暂停位置继续，收起操作界面，恢复 MV／歌词全屏。

## 自然结束、等待与重新开唱

| 场景 | 已确认行为 |
| --- | --- |
| 全屏唱完且有待播 | 自动下一首并保持全屏，无逐首确认 |
| 主界面选歌时唱完且有待播 | 后台自动下一首，保持选歌页、搜索与浏览内容，不跳全屏；可主动返回当前歌且保留进度 |
| 本场未结束但队列已唱完，后来加新歌 | 保持等待，不因队列非空自动播放；手动开始才从队首唱，之后有待播则自动续播 |

无当前歌曲时，通过胶囊展开后的演唱卡片从待播队首开始；待播也为空时进入等待画面。已有当前歌曲时通过该卡片返回演唱。不可恢复旧彩色 Logo 入口。不可用项的跳过／停止提示见 M03。

## 退出本场

- 等待画面或演唱中均可退出后回主界面，待播及顺序保留。演唱中确认退出才停止播放，将未唱完当前歌放待播队首，下次手动开始从头播；暂停继续仍从暂停处，两者分别处理。
- 演唱中先确认：“将停止当前歌曲，下次从头播放；待播队列保留。”按钮“取消／退出本场”。原本正在播放时弹窗不自动暂停 MV／声音；取消不结束本场、不回队首、不重置进度。
- 手机房间首版不实现；后续退出本场仍保留房间和手机连接，单独关闭房间规则见 [M06](M06.md#退出本场与房间生命周期)。
