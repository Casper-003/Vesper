## 当前人工复核

由用户在真实窗口操作；以下各项待验收部分只按实际反馈关闭，不因推送或其他检查通过而默认通过。

1. 曲库滚动后离开再返回，标题／工具栏／背景保持同一收缩状态，歌曲不叠在展开色块上；抽查首页、收藏、实体页和 Create，多层前进／后退及主竖／内横方向，快速导航、左右栏／队列开合及过渡中缩放无残留。
2. 实体页大图小标题、自然换行后图文居中、图片缩小淡出、紧凑栏单行；歌曲详情左右严格各半、封面居中且右侧独立滚动。窄窗、小高度及空状态不裁切，曲序解释已移除而真实资料保留；已知封面断网重启仍能使用缓存。反馈图只作修改前对照。
3. 不滚动／不开详情时采集继续推进，原未浏览歌曲艺人／专辑逐步可搜；同时增删目录和点歌保持可用，网络失败后恢复、缓存重启、修正／显式清空不被旧结果覆盖。无可靠资料保持未知；实体 performer／发行关系、多碟原曲号及未知末尾排序正确。
4. 用真实 IME 组词／提交／撤销、快速换词／清空，核对不会误点歌或迟到回填；第二批搜索→艺人→专辑→歌曲详情连续返回，恢复原词、已加载范围及稳定锚点，资料变化／锚点被删时合理回退；按真实首屏口径测端到端延迟。
5. 搜索／曲库／收藏入队、重复确认、原位撤销、按住手柄向上／下／边缘滚动、Esc／拖出取消、并发更新和键盘排序；始终操作同一条目，展开继续点歌，切页收起，不可用条目可保留管理，恢复来源、重启顺序和保存失败提示正确。合成 4K 例子不作真实多版本验收。
6. 首页引导、图标提示、目录管理弹层在小窗口与缩放时不推移列表；设置偏好、系统主题／强调色、4 单位边距、后台原生圆圈和最短一秒状态、Create 退场／恢复均按真实效果检查。快速跨行迟钝继续按搁置处理。
