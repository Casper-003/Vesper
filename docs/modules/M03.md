# M03 点歌队列与排播

更新：2026-11-04。电脑端主要交互已确认，卡片、排序／插播、撤销、不可用复核与持久化已接入；实际手势、开合观感及最新空状态仍待用户验收。真实播放与开始／返回演唱入口待 [M04](M04.md) 接入，首版不做手机点歌。检查证据见 [验证记录](../验证记录.md)，运行见 [开发与调试](../开发与调试.md)。

## 队列布局与行

- 右侧默认收起；收起约 36 单位，展开内容起始宽 400，均待实际窗口核对。并排卡片、独立浅勾边、8 圆角、4 单位间距、真实连续挤压、悬停微动与创作页整栏退场统一见 [M01](M01.md#右侧队列入口)，不重复定义。原生系统明暗主题与 Fluent 背景保留。
- 收起左缘“<”下显示待播数，含重复／不可用、不含正在演唱，空为 0；展开箭头“>”，数量仅标题“待播曲目”右侧，无右上关闭。整条可点击，展开左竖条与右留白等宽，箭头有方向／按压反馈。
- 左缘箭头或 Esc 收起，点击浏览区保持展开以继续点歌，切页收起；开合不入浏览历史，再展开恢复本次待播滚动位置。
- 顶部固定“正在演唱”，显示当前歌及播放／暂停／加载状态；当前歌不拖动。无当前歌隐藏整区及空间，下方待播独立滚动。固定并放大“待播第一首”的设想未执行。
- 歌曲行起始高约 72，顺序号、48 封面、歌名／歌手、右侧操作；字号 14／12，缺封面灰专辑图标、缺艺人“未知艺人”。长名省略，仅悬停标题滚动；点封面／歌名进歌曲详情并收起队列。
- 拖动手柄常显，移除在悬停／键盘聚焦时出现。行沿用曲库／收藏的交替底色、浅行更浅／深行更深悬停、8 圆角及稳定复用，当前歌同类效果，主题同步。滚动条有独立右留白，不盖行或按钮；曲库／收藏滚动条细则见 [M02](M02.md#概览页头与列表)。跨行高亮迟钝继续搁置。

## 电脑端排播与整理

首个完整流程应覆盖找到本地歌曲、加入队列、播放和切下一首。

| 操作 | 已确认行为 |
| --- | --- |
| 普通加入 | 按点歌先后追加待播队尾，保留已有顺序与当前演唱；手动排序后新歌仍加队尾 |
| 重复加入 | 同演唱版本已待播时提示已有位置，如“这首歌已在待播列表第 3 位，仍要再加入一次吗？”；“取消”不变，“再次加入”在队尾新增，原项不动 |
| 插播 | 右键“插播”将该项移待播首位，余项相对顺序不变，当前歌继续；首位禁用。未开唱／暂停也只调队首、不自动播放 |
| 移除 | 右键或行按钮立即移除，覆盖显示“已移除 · 撤销”5 秒，收起后仍可撤销 |
| 撤销 | 连续移除按最近一次优先逐条恢复，移除／撤销重新计时；按删除时序号恢复，超界放队尾 |

- 入队沿用音符飞向右侧队列及接收动效，短暂显示“已加入待播 · 第 N 位”，保留原开合与浏览位置。
- 拖动从右侧手柄开始，整行跟随光标、其他行实时让位、编号即时更新，近上下边缘自动滚动。松手提交新顺序；Esc、失去拖动或有效区外松手恢复原序，预览阶段不持久保存。当前歌曲不参加，当前演唱不受影响。
- 不回退成仅横向插入线或系统拖放路径。完整开合须连续挤压、文字正常比例、控件跟随真实边界，不用跳位／裁切换帧率；仅 4 单位悬停微动走轻量视觉路径，不重排歌曲／标题。

## 不可用、空状态与恢复

- 依据 [M02](M02.md#曲库目录重复文件与不可用状态) 全部已收录来源判定；全部失效才灰显“文件不可用”，浏览页隐藏选项不隐藏已待播项。仍可排序／移除／撤销，禁插播；来源恢复并复核后恢复正常。
- 轮到不可用项自动跳过并移出，短暂提示后试下一首；后续均不可用则停止推进，提示“没有可播放的待播歌曲”，等待画面归 M04。
- 空待播显示队列图形、“暂无待播／点击歌曲旁的 ＋ 点歌”；仍在演唱时保留当前区，下方为“暂无后续歌曲”。提示在待播内容区垂直居中、图标标题说明左对齐、靠内容区左边距、紧凑间距，不影响当前区／列表位置。
- 自动保存条目及顺序，关闭／重启恢复、面板默认收起，等待手动开唱。退出本场或关闭时未唱完的当前歌放回队首，其余顺序不变，下次手动开始从头播；暂停继续仍从暂停处，见 M04。
- 队列内容曾因 Canvas 内 ActualHeight 绑定未更新变为空白，现按 Host.SizeChanged 同步实际高度；绘制像素、手柄命中和实际移除 Click 的自动检查通过，仍不能替代物理拖动及观感验收。
- 用户已认可其余效果，悬停优化不扩到既有交互；性能比较区分 Debug／Release、调试器、冷／热启动，提供直接运行 Release 对照，不由一次缓存改善推定原因。

## 手机端排列（后续版本，已确认方向）

- 首版电脑由一人集中点歌，不启用按人轮唱；手机点歌及以下预设留后续。身份／权限归 [M06](M06.md)。
- 手机待播提供“一人一首”“顺序”“逆序”，作为持续模式：切换重排当前待播，后续新歌继续按模式排，当前演唱不变。
- “一人一首”按实际演唱者每轮每人一首，各人内部按点歌时间，无歌者跳过；初始轮次、新人、当前演唱者轮次及插播等边界未定。
- “顺序／逆序”的具体定义、模式与插播／重复／手动拖动的关系、切换权限均待确认。

## 提案、建议与下一步

- 用户提案（未定稿）：手机可移除待播、全员可调顺序；归属与删除权限在 M06 确定。
- 助手建议（未确认）：给插播增加可见更多菜单；重复提示加版本名／演唱者；若手机可拖动，拖后显示手动排序以免自动跳回。
- 待验收：真实物理拖动／自动滚动／取消，开合及悬停帧率，空状态与窄窗、持久化恢复。播放闭环仍不视为完成；全局接续见 [项目记忆](../../Vesper_项目记忆.md)。
