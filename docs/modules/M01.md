# M01 主界面与首页导航

更新：2026-11-04。范围：导航、首页与全局布局；歌曲详情归 [M02](M02.md)，队列操作归 [M03](M03.md)，演唱状态归 [M04](M04.md)。以下为当前已确认规则；草图中的旧入口不覆盖文字规则。

## 当前状态

主窗口、共用页头、中性／图片取色背景、空状态、队列布局及主页面竖向／详情横向导航已接入。Create 侧栏进出不闪白已获用户认可，其他新调整仍待实际观感与真实曲库键鼠验收；自动回归不能替代人工检查。首页推荐与艺人内容、创作编辑、完整演唱及新的开始／返回演唱入口尚未完成。构建、检查与证据见 [验证记录](../验证记录.md)，运行方式见 [开发与调试](../开发与调试.md)。

## 视觉与窗口

- 使用 WinUI 3、Windows Fluent 与 Mica，浅／深主题随系统应用主题在启动及系统变化时切换。旧 MD3、Flutter 与助手旧原型不作依据。
- 常规操作优先图标与悬停说明；空状态、首次引导和错误文字必须足够醒目、清楚。局部展开不推移主要列表，右侧队列的并排挤压为明确例外。未定视觉、交互及范围先确认，不从原型补充需求。
- 应用默认强调色为 Miku 蓝 `#39C5BB`，提供跟随 Windows 系统强调色的选项；主题与强调色分别处理。强调色用于按钮和选中状态，大面积背景使用下文的中性／图片配色；选项及偏好保存已接入，实际切换与恢复待验收。
- 浏览卡片与队列卡片各用半透明主题底色，NavigationView 内容基底透明，避免整页重复铺色；不由此推导其他弹窗材质。
- 内容四角圆角 8，右侧与底部各留 4 单位 Mica 外沿，形成与标题栏、侧栏连贯的包边。参考 [右上角](../../pics/M01-content-top-right.feedback.png)、[左下角](../../pics/M01-content-bottom-left.feedback.png)、[圆角](../../pics/M01-content-rounding.reference.png)、[包边](../../pics/M01-content-surround.reference.png)、[原贴边反馈](../../pics/M01-content-surround.feedback.png)；不沿用图中旧品牌标题。
- 最小窗口起始值为 900×600 界面单位，按系统缩放换算像素；保证导航和主要操作可用，实际下限待用户检查。浏览与远距离演唱分别考虑字号和信息密度。

## 一体式标题栏与浏览历史

- 顶部操作与窗口标题栏合为一行。左上固定依次为后退、前进，独立于竖向导航；不可用时禁用而不隐藏。移除软件名称、Logo 及顶部播放控件；不保留占位、预览、居中位移或替代演唱入口。右端为最小化、最大化、关闭。
- 导航按钮起始点击区 48×36，放在每侧留 4 的 56 单位格内；箭头 16 单位，与其他导航图标一致。参考 [箭头大小反馈](../../pics/M01-history-arrow-size.feedback.png)。优先官方 Frame、NavigationThemeTransition、AnimatedBackVisualSource 及原生悬停／按压反馈，前进图标镜像。
- 左侧切页和歌曲／艺人／专辑详情跳转进入原生 Frame 历史；队列开合、弹窗、进入／返回演唱不进入此历史。重复选中当前页不增加记录。
- 后退／前进恢复搜索词与滚动位置；后退后打开新页面清除旧前进路线，不手工重建历史。
- 首页、收藏、曲库、创作、设置、搜索作为主页面，彼此竖向切换；进入歌曲／艺人／专辑详情或详情间浏览横向切换。前进／后退按原跳转边恢复轴，不能将整个历史固定为横向。
- Create 仅在既有左侧导航 Selection 进出时使用 Suppress，保留其侧栏 220ms 退场／恢复。页头上卷、图片缩小淡出、同色补底、侧栏／队列、图标和操作反馈沿用各自规则，不以重置页面状态代替切换。

## 左侧竖向导航

- 从上到下为：折叠按钮、搜索、首页、收藏、曲库、创作；设置固定底部，后台活动项在设置上方。创作用于编辑已录制演唱作品，编辑功能范围未定义。
- 展开时图标加常驻文字，折叠后保留可直接切页的图标窄栏；起始宽度展开 220、折叠 56，改变主内容宽度，待实际检查后调整。折叠按钮始终在同一位置。
- 首次启动默认展开，之后记住并恢复上次状态；偏好保存已接入，实际恢复待验收。
- 搜索使用原生 NavigationView.AutoSuggestBox，位于折叠按钮下、首页上方；展开显示“搜索曲库”，收起显示放大镜，点击展开并聚焦。仅聚焦不切页、不改变选中项，非空词才进入中央结果，规则见 [M02](M02.md#搜索)。
- 折叠按钮、搜索、首页按 40 单位中心间距排列，去除搜索区域底部额外 8 单位留白。放大镜在窄栏中心与展开框右端之间作 200ms 平移，快速反向从当前位置继续，遵循系统关闭动画的设置；不影响原生输入、点击、聚焦及页面动画。
- 左侧导航开合造成的内容抽动暂不调整，保留原生开合方式。

### 后台活动仪表

- 与设置使用同级 NavigationViewItem、相同字号、行高、图标尺寸和前景色，不能弱化成小字或独立次要区域。
- 忙碌时用同色原生 ProgressRing，不旋转整张图标或进度条；折叠时保留图形，任务说明放悬停提示。
- 文字、忙碌／就绪图形和说明作为同一快照，每个已显示状态至少保持一秒；期间合并为最新快照，到期直接展示最新值，不积压旧状态，不延迟实际工作。
- 悬停可看当前任务，完成后可看最近文件数、耗时、完整核对文件数及读取量。状态不占用主内容，不阻止扫描期间增删目录、浏览和点歌。
- [后台状态参考](../../pics/M01-background-activity.reference.png)仅参考设置上方活动提示，不推导账户等入口。

## 首页内容

- 简洁留白，依次组织歌手／乐队／组合大封面、较小封面的推荐与收藏；每区一个标题、一行卡片。无内容则连标题及空间一并隐藏。
- 点击歌曲封面进详情，艺人大封面进入与歌曲行艺人名字相同的艺人详情。外部艺人卡片优先 Logo，无 Logo 用个人头像或乐队／组合合照，再无图片则用带名称的统一占位。缺图仍保留大小、位置和点击入口；歌曲占位显示歌名。
- 每区只一行，内容过多仅用左右按钮横向浏览，不用滚轮横切。窄窗保持封面尺寸，减少可见数量而不换行；整页超高时滚轮纵向浏览。
- 首版推荐从可用本地歌曲随机取一组，每次启动生成、同次运行稳定；详情或切页返回不重抽。启动时曲库为空则首次导入后生成。
- 推荐失去全部有效来源后仍保留原组：默认隐藏不可用卡片，不补抽、不改余项顺序；关闭隐藏选项时灰显并标“文件不可用”，可进详情但禁预览／入队。刷新恢复后回到原位置；整组隐藏则隐藏推荐区。
- 首页无导入按钮、不打开目录选择器。空曲库用醒目图形、28 单位标题及 16 单位说明／步骤，指向左侧“曲库”→右上文件夹加号→选择歌曲／MV 目录，并说明原文件不移动、导入后可浏览／收藏／加入待播。

## 首页与创作页的页面布局（2026-11-02）

- 首页、创作与曲库／收藏复用全宽页头、自适应标题、滚动收缩、整页右侧覆盖滚动条及窗口／队列尺寸适配。页头初始约占可用高度 0.382；细则见 [M02](M02.md#概览页头与列表)。
- 2026-11-04 用户确认采用新配色：首页、收藏、曲库、创作使用中性渐变，深色石墨灰、浅色暖灰；专辑／艺人页从已显示的固定图片提取少量低饱和色相，柔和渐变到相同正文底色。无图回退中性；系统强调色不再铺满页头，控件强调色偏好保留。
- 图片加载时从 64×64 样本在工作线程取色，颜色随图片实例复用，不在滚动中解码／取色。深浅主题切换同时更新正文底色与标题／副标题颜色；极端图片颜色不直接改变背景亮度，保持文字对比度。
- 首页原导入引导放在页头下并随整页滚动，小窗口仍可读全；创作只接布局与用途提示，不表示编辑功能已接入。
- 同色补底在 Frame 后、浏览卡片圆角内，与当前页头共享同一渐变画刷，不叠加旧黑遮罩；随页头高度／滚动裁切变化，非概览页隐藏。返回时保留滚动及标题／工具栏／背景一致的收缩状态，不用滚回顶部、删除补底或取消动画掩盖问题。

## 空状态提示与创作说明（2026-11-03）

- 收藏、曲库、创作提示在页头下内容区垂直居中，图标／标题／说明统一左对齐，提示组靠内容区左边距，两侧留 24；使用 36 单位图标、20 单位标题、14 单位说明及紧凑间距。极小高度只让提示区纵向滚动，不移动歌曲列表。
- 创作用既有编辑图标，显示“编辑演唱作品／功能尚未开放”，无新增按钮。首页引导同步左对齐，其原步骤、字句、垂直留白和整页滚动保留。
- [空状态反馈](../../pics/M01-empty-states.feedback.png)是修改前截图；具体收藏／曲库与待播内容见 M02／M03。

## 右侧队列入口

- 默认收起，展开为并排卡片并真实连续挤压浏览区；收起恢复，保留页面与滚动。卡片各自浅勾边、8 圆角、上下对齐，无公共跨卡边框或额外右阴影，队列内容与边栏是一张整体卡片。
- 底部外沿、两卡间距、右侧外沿均为 4。开合文字保持正常比例，边框／圆角／按钮随真实边界，不用端点跳位或裁切换取帧率。
- 整根竖条可点击，箭头在左缘居中：收起“<”、展开“>”，有方向与按压动效；取消右上“×”。收起数量在箭头下，展开只在标题右。展开后左缘竖条与内容右留白等宽。
- 收起悬停时仅左边向左扩 4，右边固定，浏览卡片可见右缘同步收边，保持 4/4/4。该微动使用轻量视觉过渡，不逐帧重排标题、行、按钮或改变两卡 Margin；点击完整开合继续真实宽度布局。
- 浏览区点击不关闭队列，可继续点歌；普通切页收起，队列开合不入历史。固定顶部的是当前“正在演唱”，待播列表独立滚动；“待播第一首固定并放大”未获采用。
- 创作页例外：队列内容、收起竖条和间隙整体向右退场，占位归零，创作随之伸展；沿用 220ms 连续宽度过渡。返回恢复普通收起竖条，保留条目和顺序；快速反向从当前宽度继续，缩放按最新目标收尾。
- 参考 [卡片边框与入口](../../pics/M03-card-outlines-and-toggle.feedback.png)、[等间距标注](../../pics/M01-equal-card-gaps.feedback.png)。列表、拖动、数量与排播见 M03。
