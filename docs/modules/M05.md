# M05 曲目预览

更新：2026-11-04。入口与默认声音已确认，控件外观、弹出方式待讨论，尚未实现／验收。正式演唱归 [M04](M04.md)，不得从预览推导改变正式播放或队列。

## 已确认

- 粗略预览：悬停搜索结果专辑封面，在原封面位置局部放大并静音播放 MV。
- 详细预览：在歌曲详情点封面悬浮播放图标呼出控件；封面下保留收藏／加入待播。未进入卡拉 OK 时带声音，正在卡拉 OK 时默认静音。
- 以上只确定入口与默认行为，不代表完整控件设计已确认。

## 未定提案与建议

- 用户早期提案：悬停 3 秒触发，时长待核对和原型验证。
- 助手建议：悬停预览不改行高、可关闭，指针移入保持可见；仍以原封面局部放大为基础。
- 助手建议：详细预览提供进度／暂停／声音控制；不打断、替换或自动压低正在演唱的歌曲。若演唱中允许主动开预览声音，需定义作用范围及与正式演唱的关系。
- 建议下一轮先讨论详细控件外观与弹出位置，再讨论悬停触发／退出、控制和声音边界；可准备两种状态草图。
