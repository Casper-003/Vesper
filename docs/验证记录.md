## 本地视频演唱（2026-11-06）

- 当前 `Casper-003/local-playback` 已整合胶囊分支，最终 Debug／Release x64 编译通过；最终 Release 的演唱原生隔离 **23 项**、既有预览胶囊 **52 项**通过，Core Debug **373 项**通过。报告为 `local-data/singing-check/release.json`、`preview-release.json`；早期不完整／失败检查不作为本次通过证据。
- 演唱检查以系统 MediaComposition 生成的三十秒纯色视频为输入，不读写个人曲库或偏好。覆盖：实际首帧解码及呈现回调、队首开始、旧偏好默认值、暂停／继续、返回浏览时原媒体时钟继续、两种进度模式、暂停状态定位、继续后立即隐藏控制栏、三秒闲置隐藏及再次呼出、手动切歌、浏览时自然续播、空队列等待、新增不自动开始、退出保留队列并再次从头开始、准备期间退出与晚到结果、不可用／损坏文件。
- 胶囊演唱卡整张只作入口，显示当前歌曲／待播状态；演唱控制栏用无额外圆环描边的磨砂圆形按钮。进度条在上，返回选歌在左，暂停／继续和切歌居中，退出本场在右。设置持久化“允许拖动演唱进度”，默认开启；关闭时改用只读进度。等待画面按本轮授权保持简洁，不冒充已完成歌词舞台。
- 边界：合成素材不验证真实音频听感；渲染节拍和已解码图片不证明原生视频表面在每台机器上的首帧像素。整窗全屏／恢复原窗口、首帧衔接与展开观感、实际鼠标和键盘、不同编码／长时间播放、深浅背景上的玻璃模糊及系统透明效果回退仍待用户验收。无视频的歌词演唱、B 站实际获取／播放及音频／麦克风后续能力尚未完成。
- 人工清单：①加入两首本地视频，展开胶囊点击演唱卡，核对画面／声音、首帧展开及磨砂按钮；②播放和暂停时分别返回选歌再进入，核对进度／状态不变、继续后控件收起及闲置三秒显隐；③切换两种进度设置，测试切歌／自然续播、空队列后添加歌曲不自动开始，以及退出取消与确认后的队列。

## 当前人工复核

由用户在真实窗口操作；以下各项待验收部分只按实际反馈关闭，不因推送或其他检查通过而默认通过。

1. 曲库滚动后离开再返回，标题／工具栏／背景保持同一收缩状态，歌曲不叠在展开色块上；抽查首页、收藏、实体页和 Create，多层前进／后退及主竖／内横方向，快速导航、左右栏／队列开合及过渡中缩放无残留。
2. 实体页大图小标题、自然换行后图文居中、图片缩小淡出、紧凑栏单行；歌曲详情左右严格各半、封面居中且右侧独立滚动。窄窗、小高度及空状态不裁切，曲序解释已移除而真实资料保留；已知封面断网重启仍能使用缓存。反馈图只作修改前对照。
3. 不滚动／不开详情时采集继续推进，原未浏览歌曲艺人／专辑逐步可搜，缺歌词及已确认身份的作者／作曲家图片自动缓存；观察同步时内存、CPU、滚动与切页动画。同时增删目录和点歌保持可用，网络失败后恢复、缓存重启、修正／显式清空不被旧结果覆盖。无可靠资料保持未知；实体 performer／发行关系、多碟原曲号及未知末尾排序正确。
4. 用真实 IME 组词／提交／撤销、快速换词／清空，核对不会误点歌或迟到回填；第二批搜索→艺人→专辑→歌曲详情连续返回，恢复原词、已加载范围及稳定锚点，资料变化／锚点被删时合理回退；按真实首屏口径测端到端延迟。
5. 搜索／曲库／收藏入队、重复确认、原位撤销、按住手柄向上／下／边缘滚动、Esc／拖出取消、并发更新和键盘排序；始终操作同一条目，展开继续点歌，切页收起，不可用条目可保留管理，恢复来源、重启顺序和保存失败提示正确。合成 4K 例子不作真实多版本验收。
6. 首页引导、图标提示、目录管理弹层在小窗口与缩放时不推移列表；设置偏好、系统主题／强调色、4 单位边距、后台原生圆圈和最短一秒状态、Create 退场／恢复均按真实效果检查。快速跨行迟钝继续按搁置处理。
