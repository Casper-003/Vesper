## 整库资料采集修复

用户反馈未滚入视口、未打开详情的歌曲没有艺人／专辑，导致搜索覆盖不足。原搜索阶段只保证索引读取全库已有资料，没有保证资料生产覆盖全库；当前已补齐独立采集链路。

- [LibraryEnrichmentController](../src/Vesper.App/LibraryEnrichmentController.cs) 在启动及扫描、移除、修正变化后同步当前全库候选，本地读取并发 2、联网并发 1，互不等待。Windows 宿主提供媒体读取、网络和 UI 调度，不依赖可见行或详情窗口。
- 可读文件但 Windows 属性不支持时，以空标签继续文件名联网识别；真正不可读时返回延迟重试。本地缓存 `LocalReadKey` 由来源路径及扫描长度、修改时间形成，同时保存画质；来源未变或成功资料已有时，重启复用结果。
- 仅有效元数据仍缺失且未被用户显式清空时联网。复用完整自动匹配以保留歌词佐证，可能顺带补缺歌词；不会因仅缺歌词扫描全库，也不在该队列下载封面或查询 MV。单曲后台联网流程设整体 60 秒时限。
- 本地读取完成后约 500ms 合并持久化；索引等当前构建完成再处理新批次，避免逐首保存整库或持续废弃构建。后台状态进入设置上方仪表，目录和点歌操作保持可用。
- 网络失败、无匹配和歧义分别缓存；网络失败一分钟冷却、无匹配／歧义一天冷却。成功部分结果不持续重查，未知字段仍保持未知；保存失败保留待写资料并重试。取消、来源移除、同路径替换及手动修正后，旧任务不得覆盖最新资料或补回显式清空值。
- 网易共享请求的等待方取消已隔离，成功和空结果内存缓存均有 15 分钟 TTL；后续请求不长期继承已经过期的空结果。
