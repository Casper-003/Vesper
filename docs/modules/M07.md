# M07 歌词体验

更新：2026-11-04。自动获取与详情纯文本已接入，完整演唱歌词尚未实现；显示细节、时间轴和控件仍待确定。

## 已确认

- 优先评估 Lyricify Lyrics Helper 的 .NET 能力，正式集成须验证；本地无歌词可在线匹配，保留版本选择、偏移调整和逐行回退，不保证任意曲都有逐字数据。
- 详情默认自动检索，不让搜索／选结果成为普通操作必经步骤；可靠性不足留待处理。歌名优先、艺人辅助，可忽略 Live 等后缀找曲，但 MV／专辑／现场／伴奏版时间轴不能视为一致。
- 无匹配 MV 时自动流光背景＋逐字歌词，须与实际音频版本对齐；无逐字数据如何满足目标待讨论，不把逐行文本伪作逐字时间。

## 已接入与边界

- 启动后台主动补缺歌词，无需先开详情；也保留详情按需获取。LRCLIB、网易云、酷狗互补，任一通过歌名／艺人／版本核对即可用；单源失败不拖其他来源，保留出处及缓存，断网仍可读。本地内嵌优先，同名多艺人无依据则待处理；酷狗用 LRC，解码失败或片段时长不符不冒充有效歌词。后台资源限制与重试归 [M02](M02.md#整库资料采集与搜索覆盖)。
- 显示时清除 `[id:]`、`[hash:]`、`[sign:]`、`[total:]` 等元数据与行时间标签，保留正文、正常段落标记及空行；统一处理新获取、旧缓存及内嵌歌词，无需清缓存，不改原媒体／时间轴。
- 保存原始逐行与来源给出的逐字数据；时长／显式 Live 标签仅基础兼容检查，不证明音频一致。不兼容可读正文，但不套时间轴；没有生成／伪造逐字时间。
- 已有取消、限速、Retry-After 等待、重试间隔及修正后旧任务失效。来源覆盖不能由少数样本外推全库，见 [验证记录](../验证记录.md)。
- 正式 Lyricify 集成、演唱逐字渲染、版本／偏移控件及无逐字时呈现均未完成；技术与格式核验入口见 [开发与调试](../开发与调试.md)。

## 待讨论

- MV 自带歌词时额外歌词默认状态与开关。
- 位置、字号、当前／下一句和长句呈现。
- 提前／延后调整的易懂表达及作用于单曲还是全局。
- 无逐字、无匹配歌词时的状态与流光画面细节。

建议从“MV 已带歌词，额外歌词默认如何显示”开始，可准备远距离短句／长句／逐行草图。开源处理库不等于整个应用或在线词库可直接套用。
