# M05 曲目预览

更新：2026-11-15。已按最新确认删除顶部居中的胶囊设计（含顶部预览界面与演唱入口），详情页前台预览保留，同时在 `PreviewSession` 中预留后台留存接口供后续添加后台入口使用。正式演唱归 [M04](M04.md)，不得从预览推导改变正式播放或队列。

## 已确认

- 2026-11-05 新要求覆盖此前搜索封面悬停预览方案：只在歌曲详情页提供预览入口，搜索结果／歌曲列表不提供悬停播放。鼠标移到详情专辑封面时显示磨砂玻璃背景的小播放按钮，点击后才开始预览。
- 详情预览控件包含音量、可操作进度条、暂停／继续等，保留磨砂控制条；封面下原收藏／加入待播保留。
- 详情页点击播放后使用原封面区域：音频保留封面，MV 在原区域内嵌播放，下方浮出磨砂控制条，不另开居中预览浮层。
- 2026-11-15 用户确认：彻底删除顶部居中的预览／演唱胶囊（`PlaybackCapsule`／`CapsuleGesture`），预览目前仅保留在歌曲详情页前台播放，离开详情页时自动停止当前前台预览；同时在代码中保留后台留存开关与表面绑定接口（`PreviewSession.BackgroundRetentionEnabled`、`SetBackgroundPreviewSurface`），待后续设计确定后再接入后台预览入口。正式接入仍在 Vesper 内嵌播放，不调用外部播放器或独立播放窗口。
- 预览自然结束后清理该预览会话、进度归零，详情页恢复原封面及悬浮播放按钮，隐藏整条预览控制，不停留在“预览结束”的控制条状态；再次点播放从头开始。
- 声音／打断规则：同时只保留一个预览，新预览替换旧预览；未进入演唱时预览带声音，开始正式演唱时结束旧预览。演唱中可以另开预览，但保持静音且不允许主动开声，不影响正在演唱的声音。

- 后续待讨论项：预览后台留存的界面位置与交互方式尚未确定，待用户明确设计方案后再启用预留的后台留存接口。
- 材质参考：[WinUI 应用内 Acrylic](https://learn.microsoft.com/en-us/windows/apps/develop/ui/in-app-acrylic) 与开源 [WinUI Gallery 示例](https://github.com/microsoft/WinUI-Gallery/blob/main/WinUIGallery/Samples/Acrylic/AcrylicPage.xaml)。详情页内嵌预览控制条继续沿用现有 WinUI Acrylic 与细描边；系统关闭透明效果时遵从系统回退。

## 首版实施边界

- `PreviewSession` 持有窗口级独立播放器；默认 `BackgroundRetentionEnabled = false` 时详情页卸载（`DetachDetailsPreview`）即调用 `Stop()` 结束前台预览并释放媒体表面；开启 `BackgroundRetentionEnabled` 时保留会话并可通过 `SetBackgroundPreviewSurface` 转移视频表面，供后续后台预览入口直接复用。`PreviewTransport` 提供暂停／继续、进度定位、音量和静音。支持 Windows 原生解码器可打开的本地音频／视频，联网 MV 候选链接不作为播放源。
- 已删除 `PlaybackCapsule.cs` 与 `CapsuleGesture.cs`，标题栏不再排除居中胶囊拖拽区域。
- 自动证据及人工清单见 [验证记录](../验证记录.md)，隔离入口见 [开发与调试](../开发与调试.md)。本节记录实现，不代表真实界面验收。
