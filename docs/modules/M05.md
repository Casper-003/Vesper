# M05 曲目预览

更新：2026-11-06。当前优先工作为预览；本地预览与胶囊首版已接入，真实鼠标／视觉／听感待验收。正式演唱归 [M04](M04.md)，不得从预览推导改变正式播放或队列。

## 已确认

- 2026-11-05 新要求覆盖此前搜索封面悬停预览方案：只在歌曲详情页提供预览入口，搜索结果／歌曲列表不提供悬停播放。鼠标移到详情专辑封面时显示磨砂玻璃背景的小播放按钮，点击后才开始预览。
- 详情预览控件包含音量、可操作进度条、暂停／继续等，保留磨砂控制条；封面下原收藏／加入待播保留。简易胶囊不再提供音量入口，以本节最新控件标准为准。
- 详情页点击播放后使用原封面区域：音频保留封面，MV 在原区域内嵌播放，下方浮出磨砂控制条，不另开居中预览浮层。
- 离开详情页继续播放，不因页面卸载停止。正式接入仍在 Vesper 内嵌播放，不调用外部播放器或独立播放窗口。
- 预览自然结束后清理该预览会话、进度归零，详情页恢复原封面及悬浮播放按钮，隐藏整条预览控制，不停留在“预览结束”的控制条状态；再次点播放从头开始。
- 声音／打断规则：同时只保留一个预览，新预览替换旧预览；未进入演唱时预览带声音，开始正式演唱时结束旧预览。演唱中可以另开预览，但保持静音且不允许主动开声，不影响正在演唱的声音。

## 居中胶囊（2026-11-05 确认）

- 演唱与预览组成顶部居中的整体，共用播放控制区域，不将预览固定在窗口左侧。仅预览、仅演唱及两者并存分别呈现相应状态；并存时演唱为主，预览为附属分区。
- 没有预览、也没有正在进行的演唱时，胶囊常驻，仅显示 disco 球灯 emoji `🪩`，不显示“开始演唱”文字；工具提示／辅助说明保留其开始演唱含义。正在听取使用音乐 emoji `🎵`，后接状态及曲名。短按演唱／预览胶囊均先展开控制卡，再由卡内按钮执行，不直接切换播放状态。
- 简易胶囊遵循 [控件标准图](../../pics/胶囊控件.drawio.png)：左侧封面／小视频，右侧按钮从左到右为“返回到详情页”“暂停／继续”“停止预览”，下方进度条。图形采用实心、无圆圈／无外框，深色白图形、浅色黑图形，外围面板保留磨砂；不提供音量／静音入口，音量仅在详情页调整。
- 点开展示控制时采用前后叠放的卡片，不将两个控制面板左右并排；用鼠标滚轮切换前景卡片。切换控制面板只改变展示，不开始／停止播放，也不改变进度、暂停或静音状态。前后叠放指层叠关系，不是上下排列的列表。
- 2026-11-06 用户要求展开面板统一磨砂玻璃，滚轮换卡加入动画；随后明确后层也必须运动，并移除底部“滚轮切换”小字。当前两张实体卡始终保留各自内容，同步位移／缩放，在中点交换前后层级；原前卡退至后位，原后卡升到前位，反向滚轮反向交换，不采用固定底板或中途换内容。总约 220ms，动画中不重复启动切换，系统关闭动画时直接交换。
- 仅前景卡可操作，后卡露出一小段。鼠标在卡片区域滚轮每次切一张，两张卡可循环互换；拖进度时不切换。点击外部或按 Esc 只收起，外部该次点击不传递给下方页面。过渡约 220ms，遵循系统关闭动画；标题仅超长时滚动，返回详情保留进度与暂停状态。
- 2026-11-05 用户反馈后确认：收起胶囊宽度随文字长度弹性伸缩，整个变化过程保持窗口水平居中；展开／收起从胶囊位置和体量连续过渡到控制卡，不只做整张卡淡入。标题滚动按独立经过时间推进，音量／其他状态刷新不得改变滚速。
- 点击胶囊展开显示歌曲信息／MV 简易控制，可返回对应预览详情或关闭预览；展开区域在最顶层，内部点击、拖动和切换滚轮不传递给下面的页面／列表。
- 必须保留胶囊区域的窗口拖动能力：按下瞬间不展开，短按松开才视为点击；持续按住不展开，按住移动可拖动窗口，拖窗结束松开也不触发展开。不能先展开后再判断拖动。该规则针对胶囊本体，不能把展开后的进度控件拖动误作拖窗。按钮单次点击即可执行，卡片内指针按下／松开交给原生控件；外围覆盖层仅拦截卡片外操作。

## 首版实施边界

- `PreviewSession` 持有窗口级独立播放器；详情卸载只转移视频表面，不销毁播放；`PreviewTransport` 提供暂停／继续、进度定位、音量和静音。支持 Windows 原生解码器可打开的本地音频／视频，联网 MV 候选链接不作为播放源。
- `PlaybackCapsule` 提供顶层覆盖、叠卡滚轮切换、返回详情、关闭预览和标题滚动。胶囊区域从原生标题栏拖动矩形中排除以接收短按；移动超过阈值后移交 Windows 原生拖窗，长按／取消／捕获丢失不能触发点击。
- 展开前后层使用 `FrostedPanel` 原生 Acrylic，独立设置 TintOpacity／TintLuminosityOpacity 为 0.72，深浅配色及系统回退保留；收起胶囊沿用原材质。材质配置检查不能代替真实背景上的模糊／雾化观感验收。
- 两卡各自常驻 `Border` 并拥有独立 Pose，整体展开由共同 deck 处理；只对前卡开放鼠标操作，换位时焦点暂回胶囊，避免后卡收到旧按键。换位／收起保留预览视频表面至展开层隐藏；中途收起先捕获两卡有效位置，再整体从原处缩回，过期回调不得复活卡片。换卡不降低整卡透明度来制造内容重影。
- 实心图标的路径以 24 单位绘制，在 18×18 的 PathIcon 中显式缩放为 0.75，不能只设控件宽高而裁掉箭头尖端；原生像素检查覆盖返回／播放尖端、停止方块及暂停双条的居中。2026-11-06 用户认可修正后的图标，不将此扩大为磨砂或整套播放流程已验收。
- 演唱卡目前明确提示未接入，卡内开始按钮禁用；不触发假播放或消耗待播队列。双卡展示及声音策略可用隔离会话验证，真实演唱／返回接线仍归 M04 后续工作。
- 自动证据及人工清单见 [验证记录](../验证记录.md)，隔离入口见 [开发与调试](../开发与调试.md)。本节记录实现，不代表真实界面验收。
