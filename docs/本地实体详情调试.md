- 专辑只列本地已有歌曲，读取 Windows `System.Music.AlbumArtist`、`System.Music.PartOfSet`、`System.Music.TrackNumber`。保留原始碟号／曲号；缺曲号的歌曲放末尾按歌名排列，全部缺失时显示简短说明，不拿列表行号冒充曲序。
- 艺人、专辑使用持久化本地身份，保留外部资料映射；曲序保存在发行版成员关系中。歌曲身份、收藏及待播关系沿用既有路径；用户纠正某首歌归属时不改名其他歌曲共享的实体。
- 资料更新合并刷新，滚动或按住期间延后重排；已知封面通过既有载图路径后台加载并增加磁盘缓存，不启动额外歌曲资料或 MV 查询。

## 整库资料采集修复

用户反馈未滚入视口、未打开详情的歌曲没有艺人／专辑，导致搜索覆盖不足。原搜索阶段只保证索引读取全库已有资料，没有保证资料生产覆盖全库；当前已补齐独立采集链路。

- [LibraryEnrichmentController](../src/Vesper.App/LibraryEnrichmentController.cs) 在启动及扫描、移除、修正变化后同步当前全库候选，本地读取并发 2、联网并发 1，互不等待。Windows 宿主提供媒体读取、网络和 UI 调度，不依赖可见行或详情窗口。
- 可读文件但 Windows 属性不支持时，以空标签继续文件名联网识别；真正不可读时返回延迟重试。本地缓存 `LocalReadKey` 由来源路径及扫描长度、修改时间形成，同时保存画质；来源未变或成功资料已有时，重启复用结果。
- 仅有效元数据仍缺失且未被用户显式清空时联网。复用完整自动匹配以保留歌词佐证，可能顺带补缺歌词；不会因仅缺歌词扫描全库，也不在该队列下载封面或查询 MV。单曲后台联网流程设整体 60 秒时限。
- 本地读取完成后约 500ms 合并持久化；索引等当前构建完成再处理新批次，避免逐首保存整库或持续废弃构建。后台状态进入设置上方仪表，目录和点歌操作保持可用。
- 网络失败、无匹配和歧义分别缓存；网络失败一分钟冷却、无匹配／歧义一天冷却。成功部分结果不持续重查，未知字段仍保持未知；保存失败保留待写资料并重试。取消、来源移除、同路径替换及手动修正后，旧任务不得覆盖最新资料或补回显式清空值。
- 网易共享请求的等待方取消已隔离，成功和空结果内存缓存均有 15 分钟 TTL；后续请求不长期继承已经过期的空结果。

## 用户人工检查清单

1. 启动后不滚动曲库、不打开歌曲详情，观察后台仪表推进；用原来未浏览过的歌曲的艺人／专辑搜索，核对资料会随后台完成后出现。歌曲真实无可靠资料时应保持未知，不因全库任务结束就标为全部识别。
2. 后台读取和联网时继续点歌、添加／移除目录；确认前台可用、旧目录结果不恢复。对网络失败后恢复、重启复用缓存及用户修正／清空值分别抽查。
3. 搜索一个本地已有艺人和专辑，分别点击两张卡片；核对艺人歌曲及相关专辑正确，没有混入仅作曲的歌曲。
4. 按“搜索 → 艺人 → 相关专辑 → 歌曲详情 → 连续返回”浏览，检查搜索词、已加载结果和各页滚动位置恢复；同时试前进。
5. 用只收录第 02、07 首、含多碟编号及部分无曲号的专辑核对顺序；全无曲号时确认按歌名排列并显示说明。
6. 在详情页收藏／取消收藏、加入待播，检查与曲库、收藏和队列共享同一首歌；资料修正、目录变化后确认页面关联及不可用规则正确。
7. 检查已有封面加载；重启并断网后检查已缓存封面及本地浏览。艺人缺图应保留占位，不用专辑封面冒充艺人头像。
8. 缩窄窗口、展开／收起左栏及右侧队列，滚动至页头收缩再返回顶部；核对标题、图片、曲号和操作按钮不裁切或重叠，后台资料更新不移动按住的歌曲。
