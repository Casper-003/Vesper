## 视觉与窗口

- 使用 WinUI 3、Windows Fluent 与 Mica，浅／深主题随系统应用主题在启动及系统变化时切换。旧 MD3、Flutter 与助手旧原型不作依据。
- 常规操作优先图标与悬停说明；空状态、首次引导和错误文字必须足够醒目、清楚。局部展开不推移主要列表，右侧队列的并排挤压为明确例外。未定视觉、交互及范围先确认，不从原型补充需求。
- 应用默认强调色为 Miku 蓝 `#39C5BB`，提供跟随 Windows 系统强调色的选项；主题与强调色分别处理。强调色用于按钮和选中状态，大面积背景使用下文的中性／图片配色；选项及偏好保存已接入，实际切换与恢复待验收。
- 浏览卡片与队列卡片各用半透明主题底色，NavigationView 内容基底透明，避免整页重复铺色；不由此推导其他弹窗材质。
- 内容四角圆角 8，右侧与底部各留 4 单位 Mica 外沿，形成与标题栏、侧栏连贯的包边。参考 [右上角](../../pics/M01-content-top-right.feedback.png)、[左下角](../../pics/M01-content-bottom-left.feedback.png)、[圆角](../../pics/M01-content-rounding.reference.png)、[包边](../../pics/M01-content-surround.reference.png)、[原贴边反馈](../../pics/M01-content-surround.feedback.png)；不沿用图中旧品牌标题。
- 最小窗口起始值为 900×600 界面单位，按系统缩放换算像素；保证导航和主要操作可用，实际下限待用户检查。浏览与远距离演唱分别考虑字号和信息密度。

## 一体式标题栏与浏览历史

- 顶部操作与窗口标题栏合为一行。左上固定依次为后退、前进，独立于竖向导航；不可用时禁用而不隐藏。右端为最小化、最大化、关闭。旧软件名称、Logo 及旧顶部播放控件继续移除，不恢复原占位或旧演唱入口。
- 2026-11-15 用户确认：彻底删除顶部居中的胶囊设计（含顶部演唱入口与预览卡片），演唱入口迁移至主界面右侧栏上半部分，标题栏恢复为左端历史按钮与右端窗口按钮之间的纯拖窗空白区；曲目预览回归歌曲详情页前台播放并预留后台留存接口，见 [M05](M05.md)。
- 导航按钮起始点击区 48×36，放在每侧留 4 的 56 单位格内；箭头 16 单位，与其他导航图标一致。参考 [箭头大小反馈](../../pics/M01-history-arrow-size.feedback.png)。优先官方 Frame、NavigationThemeTransition、AnimatedBackVisualSource 及原生悬停／按压反馈，前进图标镜像。
- 左侧切页和歌曲／艺人／专辑详情跳转进入原生 Frame 历史；队列开合、弹窗、进入／返回演唱不进入此历史。重复选中当前页不增加记录。
- 后退／前进恢复搜索词与滚动位置；后退后打开新页面清除旧前进路线，不手工重建历史。
- 首页、收藏、曲库、创作、设置、搜索作为主页面，统一使用原生竖向滑动切换（`SlideNavigationTransitionEffect.FromBottom`，后退时自动反向），不再对创作页使用无动画 `SuppressNavigationTransitionInfo`；进入歌曲／艺人／专辑详情或详情间浏览横向切换。前进／后退按原跳转边恢复轴，不能将整个历史固定为横向。
- 页头上卷、图片缩小淡出、同色补底、侧栏／队列、图标和操作反馈沿用各自规则，不以重置页面状态代替切换。

## 左侧竖向导航

- 从上到下为：折叠按钮、搜索、首页、收藏、曲库、创作；设置固定底部，后台活动项在设置上方。创作用于编辑已录制演唱作品，编辑功能范围未定义。
- 展开时图标加常驻文字，折叠后保留可直接切页的图标窄栏；起始宽度展开 220、折叠 56，改变主内容宽度，待实际检查后调整。折叠按钮始终在同一位置。
- 首次启动默认展开，之后记住并恢复上次状态；偏好保存已接入，实际恢复待验收。
- 搜索使用原生 NavigationView.AutoSuggestBox，位于折叠按钮下、首页上方；展开显示“搜索曲库”，收起显示放大镜。2026-11-16 更新：用户点击或键盘聚焦搜索框（含收起态点击放大镜展开）时立即切换到“搜索”页面并保留输入框焦点，不再停留在原页面，规则见 [M02](M02.md#搜索)。
- 折叠按钮、搜索、首页按 40 单位中心间距排列，去除搜索区域底部额外 8 单位留白。放大镜在窄栏中心与展开框右端之间作 200ms 平移，快速反向从当前位置继续，遵循系统关闭动画的设置；不影响原生输入、点击、聚焦及页面动画。
- 左侧导航开合造成的内容抽动暂不调整，保留原生开合方式。

### 后台活动仪表

- 与设置使用同级 NavigationViewItem、相同字号、行高、图标尺寸和前景色，不能弱化成小字或独立次要区域。
- 忙碌时用同色原生 ProgressRing，不旋转整张图标或进度条；折叠时保留图形，任务说明放悬停提示。
- 文字、忙碌／就绪图形和说明作为同一快照，每个已显示状态至少保持一秒；期间合并为最新快照，到期直接展示最新值，不积压旧状态，不延迟实际工作。
- 悬停可看当前任务，完成后可看最近文件数、耗时、完整核对文件数及读取量。状态不占用主内容，不阻止扫描期间增删目录、浏览和点歌。
- [后台状态参考](../../pics/M01-background-activity.reference.png)仅参考设置上方活动提示，不推导账户等入口。

## 首页内容（2026-11-16 四区大屏版已接入，待人工验收）

- 2026-11-16 用户确认最新首页方案并移除原有的 `Home` 标题大卡片页头、旧三排卡片与空库导入横幅，改为严格对照 [首页草图](../../pics/homepagedrawio.png) 的 **四区大屏 KTV 控制台**，详见 [M08](M08.md#首页-ktv-控制台2026-11-16-四区大屏版已接入)：
  - **左侧竖向长条**：集中放置全部音频推子与实时麦克风电平灯柱（MIC 人声推子、红／绿实时电平表、耳返开关、BGM 伴奏推子）；大屏／高窗显示竖向物理推子，小屏／窄窗自动切换为旋钮。
  - **中间上方：演唱界面大屏幕**：居中放置且四周留出呼吸外边距（不沾满中间区域）；平时无按钮遮挡，光标移入时淡入居中毛玻璃按钮，点击以类似 Win11 窗口放缩动画全屏进入演唱模式；有本地 MV 时展示视频首帧，无视频的歌曲不直接贴静态专辑封面图而改以专辑提取色渲染纯色舞台与周围环境柔光，无歌曲时显示灰色版软件 Logo 占位。
  - **中间下方横向长条**：极简硬件参数与固定状态槽（麦克风／输出设备、刷新、共享／独占切换及原伴／升降调／混响占位）；文字尽量少，且文字产生／消失均放在固定宽高槽位内，绝不引发任何控件移位。
  - **右侧竖向长条**：首页内嵌待播列表，直接展示当前演唱与待播队列并支持移除、插播、跳转详情与拖拽排序。
- **与设置页同步**：设置页保留相同的音频设备、模式、音量及电平表样式（分段 LED／连续平滑）等配置，首页与设置页实时同步变动。
- **施工状态**：2026-11-16 已在 `Casper-003/home-refactor` 分支完成四区大屏版实现（Debug x64 编译通过，0 警告 0 错误），待用户手动检查观感、动画、零移位表现与真实音频设备效果。

## 创作页与概览页头（2026-11-02 / 2026-11-16 更新）

- 创作、曲库与收藏继续复用全宽页头、自适应标题、滚动收缩、整页右侧覆盖滚动条及窗口／队列尺寸适配（首页不再使用该大卡片页头，改用四区控制台直铺全卡）。页头初始约占可用高度 0.382；细则见 [M02](M02.md#概览页头与列表)。
- 2026-11-04 用户确认采用新配色：首页、收藏、曲库、创作使用中性渐变，深色石墨灰、浅色暖灰；专辑／艺人页从已显示的固定图片提取少量低饱和色相，柔和渐变到相同正文底色。无图回退中性；系统强调色不再铺满页头，控件强调色偏好保留。
- 图片加载时从 64×64 样本在工作线程取色，颜色随图片实例复用，不在滚动中解码／取色。深浅主题切换同时更新正文底色与标题／副标题颜色；极端图片颜色不直接改变背景亮度，保持文字对比度。
- 首页原导入引导放在页头下并随整页滚动，小窗口仍可读全；创作只接布局与用途提示，不表示编辑功能已接入。
- 同色补底在 Frame 后、浏览卡片圆角内，与当前页头共享同一渐变画刷，不叠加旧黑遮罩；随页头高度／滚动裁切变化，非概览页隐藏。返回时保留滚动及标题／工具栏／背景一致的收缩状态，不用滚回顶部、删除补底或取消动画掩盖问题。

## 右侧队列入口

- 非首页与非创作页继续保留主窗口右侧**上下双卡片结构**（2026-11-15 已定稿）：上半部分为演唱入口预览卡片（`SingingShell`／`SingingCard`），下半部分为待播队列卡片（`QueueShell`），中间 4 单位间隙支持上下拖动调整比例（持久化 `RightSplitRatio`），默认 `0.382 : 0.618`，宽度固定（收起 36、展开 400），设置页保留 `LinkRightPanels` 联动开关。
- 默认收起，展开为并排或浮层卡片；卡片浅勾边、8 圆角、上下对齐，顶部／底部／左右／上下间隙均为 4。开合文字保持正常比例，边框／圆角／按钮随真实边界，不用端点跳位或裁切换取帧率。
- **收起／展开外观**：收起态平时为空白窄条，光标移入时通过 220ms 显式渐变动画平滑浮现后方内容（`0 -> 0.5`）并在垂直居中淡入“<”（`0 -> 1`，移出 180ms 淡出），消除瞬间显示；展开态去除左右 34 单位边框竖条占位，左上角收起按钮“>”仅在光标移入对应卡片（或获焦）时淡入，待播标题“待播曲目”固定水平居中、数量保持右对齐。
- 浏览区点击不关闭右侧栏，可继续点歌；普通切页收起，右侧栏开合不入历史。队列固定顶部的是当前“正在演唱”，待播列表独立滚动。
- **首页与创作页退场例外**：在“首页”与“创作”页面时，主窗口右侧双栏整体向右退场且伴随 220ms 宽度＋透明度渐入渐出动画，占位归零（首页右侧改为直接内嵌展示待播列表，首页中心大屏承担演唱入口）；切到曲库／收藏／搜索／设置／详情页后平滑渐入恢复右侧双栏，保留条目、顺序与比例。
- 参考 [卡片边框与入口](../../pics/M03-card-outlines-and-toggle.feedback.png)、[等间距标注](../../pics/M01-equal-card-gaps.feedback.png)。列表、拖动、数量与排播见 M03。
